1. Differences Between Native, Hybrid, and Cross-Platform Development
   Native Development
   Definition: Built for one specific operating system.
   Languages: Swift/Objective-C (iOS), Kotlin/Java (Android).
   Performance: Highest speed and responsiveness.
   Access: Full access to device hardware.
   When used: High-performance apps like heavy games.
   Hybrid Development
   Definition: Web apps wrapped inside a native container.
   Languages: HTML, CSS, JavaScript (Cordova, Ionic).
   Performance: Slower with limited offline capabilities.
   Access: Restricted access to device features via plugins.
   When used: Simple apps with tight budgets.
   Cross-Platform Development
   Definition: One codebase compiled into native code for multiple platforms.
   Languages: Dart (Flutter), JavaScript/TypeScript (React Native).
   Performance: Near-native speed and smooth UI rendering.
   Access: Good access to most native hardware APIs.
   When used: Faster multi-platform launches with shared logic.

2. The Flutter Ecosystem and Its Benefits
   What is it?
   Framework: Google’s open-source UI toolkit for building natively compiled applications.
   Language: Powered exclusively by the Dart programming language.
   Engine: Uses the Skia/Impeller graphics engine for direct pixel rendering.
   How it helps developers:
   Single Codebase: Write once, deploy to iOS, Android, Web, and Desktop.
   Hot Reload: Visualizes code changes in sub-seconds without restarting the application.
   Custom Widgets: Offers a vast library of pre-designed, highly customizable UI components.
   Pub.dev: Accesses an extensive registry of open-source packages and plugins.

3. Software Development Life Cycle (SDLC) and Its Importance
   Core Phases:
   Planning: Defining project goals, target audience, and feasibility.
   Requirements: Gathering detailed feature lists and technical specifications.
   Design: Creating UI layouts, system architectures, and database models.
   Development: Writing actual clean, maintainable source code.
   Testing: Verifying quality, performance, and fixing software bugs.
   Deployment: Releasing the application to production app stores.
   Maintenance: Monitoring performance, fixing errors, and adding updates.
